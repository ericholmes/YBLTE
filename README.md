## YBLTE Interactive Dashboard
The Yolo Bypass Lower Trophic Enhancement (YBLTE) Dashboard provides an interactive overview of project sites, restoration areas, and water‑quality patterns across the Yolo Bypass. It includes an interactive Leaflet map, water‑quality heatmaps, and animated visualizations.
